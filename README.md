# Zombie Apocalypse SMP

Minecraft 1.21.1 + NeoForge 기반의 멀티플레이 좀비 아포칼립스 모드 프로젝트입니다.

## 개발 환경
- Java 21 (JDK)
- Minecraft 1.21.1
- NeoForge 21.1.264
- Gradle / ModDevGradle

## 프로젝트 목표
- 유튜버 20~30명 규모의 시즌제 PvPvE 생존 서버
- 감염, 좀비 AI, 거점 약탈, 총기, 차량 및 경제 시스템
- 8,000 x 8,000 블록 월드와 좀비 대이동 이벤트

## 진행 상태
- [x] NeoForge 개발 템플릿 설치
- [x] 개발용 Minecraft 클라이언트 실행 확인
- [ ] 모드 ID 및 Java 패키지를 프로젝트용으로 변경
- [x] 첫 커스텀 좀비 구현
- [ ] 실제 게임 소리(총성/마이크)에 반응하는 AI 개발

## 개발용 Minecraft 실행 (Windows)

```powershell
.\gradlew.bat runClient
```

> 현재 게임 코드는 NeoForge 기본 예제 단계입니다. 위에 적힌 게임 기능은 앞으로 차례대로 개발할 계획입니다.

## 소리 조사 AI 첫 테스트 (개발용)
1. 치트가 켜진 테스트 월드에서 `/summon zombieapocalypse:infected ~12 ~ ~`로 감염자를 소환합니다.
2. 감염자와 플레이어 사이에 벽이나 장애물이 있어 **서로 보지 못하도록** 한 뒤, 플레이어가 24블록 이내에서 `/za_noise`를 입력합니다.
3. 명령어가 모루 소리를 내며 주변 감염자에게 해당 위치를 조사하라고 알립니다. 감염자는 길이 있으면 이동하려고 시도하며, 플레이어를 발견하면 기존 공격 AI를 우선합니다.
4. 명령어 응답의 `alerted` 숫자로 통지를 받은 감염자 수를 확인합니다.

이 단계는 **가짜 테스트 소리를 수동으로 발생시키는 기능**입니다. 아직 마이크, 발소리, 블록 파괴, 총성에 자동 반응하지 않으며, 감염자는 경로 탐색에 실패하면 목적지까지 도착하지 못할 수도 있습니다.
