# Zombie Apocalypse SMP

Minecraft 1.21.1 + NeoForge 기반의 멀티플레이 좀비 아포칼립스 모드 프로젝트입니다.

## 개발 환경
- Java 21 (JDK)
- Minecraft 1.21.1
- NeoForge 21.1.264
- Gradle / ModDevGradle

## 프로젝트 목표
- 유튜버 20~30명 규모의 시즌제 PvPvE 생존 서버
- 감염, 좀비 AI, 거점 약탈, 총기, 차량 및 경제 시스템
- 8,000 x 8,000 블록 월드와 좀비 대이동 이벤트

## 진행 상태
- [x] NeoForge 기본 개발 환경 설치 및 실행
- [x] 프로젝트 고유 모드 ID (`zombieapocalypse`) 적용
- [x] 첫 커스텀 감염자 구현 및 소환 테스트
- [x] 수동 소리 조사 테스트 (`/za_noise`)
- [ ] 플레이어 블록 파괴·설치 및 폭발 이벤트 조사 (코드 작성, 인게임 검증 필요)
- [ ] 발소리·총성·마이크 소리 연동

## 개발용 Minecraft 실행 (Windows)

```powershell
.\gradlew.bat runClient
```

## 현재 구현된 소리 감지

| 게임 행동 | 감염자 탐지 반경(초기값) |
| --- | ---: |
| 플레이어가 블록 파괴 | 16블록 |
| 플레이어가 블록 설치 | 10블록 |
| 폭발(TNT 등) | 48블록 |
| 테스트 명령어 `/za_noise` | 24블록 |

서버의 이벤트를 직접 처리하므로, **모든 소리 파일을 듣는 시스템은 아닙니다.** 게임에서 블록을 파괴하거나 설치하는 플레이어의 행동, 실제 폭발 이벤트에만 반응합니다. 파괴·설치가 취소된 경우 알리지 않도록 처리합니다.

감염자는 **현재 공격 대상이 없을 때** 마지막 소리 위치를 최대 12초 동안 조사합니다. 플레이어를 발견하면 기존의 추격·공격 AI가 우선합니다. 길이 막혀 있으면 해당 위치에 도달하지 못할 수 있습니다.

## 인게임 소리 감지 테스트

1. GitHub Desktop으로 코드를 업데이트한 뒤 개발용 클라이언트를 다시 실행합니다.
2. 치트가 켜진 크리에이티브 테스트 월드에서 `/summon zombieapocalypse:infected ~12 ~ ~`로 감염자를 소환합니다.
3. 감염자와 12블록 정도 거리를 유지하며, **플레이어 쪽에서** 흙이나 돌 블록을 설치하고 파괴해 보세요. 감염자가 소리 위치를 향해 움직이는지 확인합니다.
4. 폭발은 다른 위치에 TNT를 설치하고 점화하여 감염자가 폭발 위치로 향하는지 확인할 수 있습니다. 테스트 월드 손상에 주의하세요.
5. 비교용으로 `/za_noise` 명령어를 입력해 수동 신호 반응도 테스트해 볼 수 있습니다.

**주의:** 아직 발소리, 문 여닫기, 음성 채팅, 총기 소리는 연결되어 있지 않습니다. 모든 테스트 결과는 게임 플레이로 추가 검증이 필요합니다.
