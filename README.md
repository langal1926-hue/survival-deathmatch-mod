# Zombie Apocalypse SMP

Minecraft 1.21.1 + NeoForge 기반의 멀티플레이 좀비 아포칼립스 모드 프로젝트입니다.

## 개발 환경
- Java 21 (JDK)
- Minecraft 1.21.1
- NeoForge 21.1.264
- Gradle / ModDevGradle

## 프로젝트 목표
- 유튜버 20~30명 규모의 시즌제 PvPvE 생존 서버
- 감염, 좀비 AI, 거점 약탈, 총기, 차량 및 경제 시스템
- 8,000 x 8,000 블록 월드와 좀비 대이동 이벤트

## 소리 감지 규칙 (초기 밸런스)

| 행동 | 감염자 탐지 반경 |
| --- | ---: |
| 웅크리고 이동 | 2.5블록 |
| 일반 걷기 | 7블록 |
| 전력 질주 | 16블록 |
| 문·덫문·울타리 문 여닫기 | 12블록 |
| 블록 파괴 | 16블록 |
| 블록 설치 | 10블록 |
| TNT 등 폭발 | 48블록 |
| `/za_noise` 테스트 명령어 | 24블록 |

- 발소리는 서버에서 **8틱마다 위치 변화를 샘플링**해 발생시키는 근사 방식입니다. 단순 음향 재생에 반응하는 것은 아닙니다.
- 달리지 않고 웅크려 이동하면 감지 반경이 작아집니다. 땅에 서서 움직이는 경우만 대상이며 수영·비행·탑승 중에는 발생시키지 않습니다.
- 문·덫문·울타리 문은 **실제로 열림 상태가 바뀐 경우에만** 소리 신호를 보냅니다. 플레이어가 직접 우클릭해서 상태가 바뀌는 경우를 감지하며, 레드스톤으로만 열리는 경우는 이번 버전 범위 밖입니다.
- 실제 AI는 대상 플레이어를 이미 발견하면 추격·공격을 우선합니다. 길 찾기 장애물이 있으면 소리 위치에 도달하지 못할 수도 있습니다.
- 감염자는 서버가 보내는 알림에만 반응합니다. **실제 마이크, 총소리, 일반 게임 음향 전체를 듣지는 않습니다.**

## 휴대용 경보기 아이템 테스트

첫 실사용 아이템 **휴대용 경보기 (시험용)** 를 추가했습니다. 총기는 아직 없으므로 큰 소리를 내는 간단한 테스트 도구입니다.

- 획득(치트 허용): `/give @s zombieapocalypse:noise_emitter`
- 손에 든 상태로 우클릭하면 **플레이어 위치에서** 모루 소리와 음표 입자가 발생합니다.
- 반경 **40블록** 안의 커스텀 감염자에게 소리 위치를 조사하라는 신호를 보냅니다.
- **3초(60틱) 재사용 대기시간**, 무제한 사용(현재는 테스트용)
- 외형은 임시로 기본 화염구 아이콘을 사용합니다. 추후 전용 모델을 만들 수 있습니다.
- 플레이어 근처에서 소리가 나기 때문에 감염자를 **자기 쪽으로 유인**합니다. 던지는 장치는 아직 아닙니다.

**테스트 방법:** 게임을 종료한 뒤 GitHub Desktop에서 Pull 하고 개발용 클라이언트를 다시 실행합니다. 크리에이티브 테스트 월드에서 `/summon zombieapocalypse:infected ~25 ~ ~`로 감염자를 소환한 다음 `/give @s zombieapocalypse:noise_emitter`로 아이템을 받습니다. 감염자와 약 25블록 떨어진 위치에서 경보기 아이템을 우클릭하면, 기존 발소리 탐지 거리(최대 16블록)보다 먼 곳에서도 감염자가 조사하러 와야 합니다.

## 인게임 테스트

1. GitHub Desktop에서 `Fetch origin → Pull origin` 후 개발용 마인크래프트를 실행하세요.
2. 치트 허용 크리에이티브 월드에서 `/summon zombieapocalypse:infected ~12 ~ ~`로 감염자를 소환하세요. (크리에이티브에서는 기존 시각 추격 AI가 개입하지 않아서 소리 테스트가 편합니다.)
3. **달리기**: 감염자와 약 12블록 거리에서 달려 보세요. 감염자가 발소리 위치를 조사하는지 확인하세요.
4. **일반 걷기**: 감염자와 5~7블록 거리에서 걸어 보세요.
5. **웅크리기**: 약 6블록 이상 떨어져 웅크려 이동하면 발소리만으로는 감지되지 않아야 합니다. 주변 블록 파괴·설치로 발생하는 소리는 별개입니다.
6. **문**: 감염자와 10블록 정도 떨어진 상태에서 나무문을 직접 열고 닫아 보세요.
7. 구분이 어려우면 `/za_noise`로 기존 명령어 감지가 유지되는지 비교 테스트하세요.

테스트 월드의 다른 몹, 장애물, 기존 탐색 위치 등에 따라 동작이 달라질 수 있습니다. 테스트에서 이상이 발견되면 이벤트 감지 및 동작 방식을 조정합니다.
