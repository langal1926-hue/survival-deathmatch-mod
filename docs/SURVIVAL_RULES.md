# 채굴·제작 제한

이 서버는 파밍과 거래로 물자를 확보합니다. 이 단계는 공급 경로를 제한하는 작업이며,
자동 재보급 상자와 상인 시스템은 다음 단계입니다. 테스트 월드에는 관리자가 물자를 지급하세요.

## 적용 규칙

- 서바이벌·어드벤처 플레이어는 어떤 블록도 직접 파괴할 수 없습니다. 자신이 설치한 블록도 포함합니다.
- 크리에이티브에서는 맵 편집을 위해 블록 파괴를 허용합니다. OP도 서바이벌 모드라면 예외가 아닙니다.
- **모든 게임 모드에서 모든 JSON 조합법을 로드하지 않습니다.** 2×2 인벤토리 제작,
  3×3 제작대, 레드스톤 자동 제작기, 화로·용광로·훈연기·모닥불 조리,
  석재 절단과 대장장이 조합이 포함됩니다. 모드/데이터팩이 추가한 조합법도 같은 규칙을 적용합니다.
- 서버 시작과 `/reload` 때마다 규칙을 적용합니다. 서버가 클라이언트에 보내는 조합법도 비어 있으므로
  레시피북·Shift 클릭·자동 제작으로 결과물을 만들 수 없습니다. 재료를 사후 삭제하지 않습니다.
- 제작·가공 작업대, 양조기, 인챈트 테이블, 숫돌, 베틀, 지도 제작대와 모든 모루는 열 수 없습니다.
  블록 클릭을 거치지 않고 열린 해당 바닐라 메뉴도 서버에서 닫습니다.
- 호퍼로 재료가 들어가는 기존 양조기의 제조 이벤트도 취소합니다.
- TaCZ 제작대 4종 차단과 총기 14종·부착물 제한은 계속 적용합니다.
- **상자·통·개인 인벤토리, 문·덫문·울타리문, 블록 설치, 총기 사용과 재장전은 유지합니다.**
- 크리에이티브 관리자는 아이템 목록이나 `/give`로 맵과 테스트 물자를 준비합니다. 제작 제한에는 예외가 없습니다.

기존 상자나 작업대의 완성품을 소급 삭제하지 않습니다. 폭발·몹·피스톤·물 등으로 인한
환경 파괴, 기본 몹 드롭, 별도 모드의 독자적인 가공 기계는 이번 플레이어 채굴/제작 제한의 범위 밖입니다.
새 모드를 추가하면 조합법 시스템을 거치지 않는 생산 경로를 별도로 점검해야 합니다.

## 검증

`bash gradlew build`는 실제 NeoForge 테스트 환경에서 JUnit 회귀 테스트를 실행합니다.
테스트는 서버 데이터팩 로드 후 조합법 제거, 제작 입력 보존, 생존/모험 파괴 차단,
크리에이티브 편집 예외, 양조 취소와 상자/인벤토리 접근 유지를 확인합니다.

게임에서는 새 테스트 월드를 사용하거나 기존 월드를 백업하고 다음을 확인하세요.

1. 크리에이티브에서 돌, 상자, 문, 제작대, 화로와 자동 제작기를 배치하고 판자·원석·연료를 준비합니다.
2. `/gamemode survival` 후 돌과 자신이 설치한 블록을 부숴 봅니다. 파괴/드롭이 발생하면 안 됩니다.
3. 인벤토리 2×2에 판자 4개를 넣습니다. 제작대 결과가 나오지 않고 재료가 보존되어야 합니다.
4. 제작대·화로·모루 등을 누르면 안내가 표시되고 사용이 차단되어야 합니다.
5. 미리 재료를 넣은 자동 제작기에 레드스톤 신호를 보내고, 화로/양조기에 호퍼로 재료를 공급해도 제품이 나오면 안 됩니다.
6. `/reload` 후 3~5번을 반복합니다.
7. 상자 파밍, 문 개폐, 블록 설치와 TaCZ 발사·재장전이 정상인지 확인합니다.
8. `/gamemode creative`에서는 맵 블록을 다시 파괴할 수 있어야 합니다.

상자 60분 재보급과 상인은 아직 구현되지 않았으므로, 테스트용 아이템은 관리자가 공급합니다.
