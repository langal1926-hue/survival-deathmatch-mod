# Phase 02 — 생존 규칙과 도시 보호

Minecraft 1.21.1 / NeoForge 21.1.264. 이번 단계는 **서버 권한 기준**으로 적용됩니다.

## 적용된 규칙

- **채굴 불가:** 서버의 기존 지형·건물은 플레이어가 파괴할 수 없습니다. 소유자가 직접 배치한 건축 블록만 철거할 수 있습니다. 다른 플레이어가 설치한 블록은 파괴할 수 없습니다.
- **설치 제한:** 플레이어는 일반 블록 아이템을 배치할 수 없습니다. 허가된 `zombieapocalypse:construction_*` 아이템과 **바닐라 상자(`minecraft:chest`), 모든 색상의 바닐라 침대**를 배치할 수 있습니다. 위치·소유자 UUID가 차원별 SavedData에 저장되어 재시작 후에도 유지됩니다.
- **제작 불가:** 서버 RecipeManager에서 조합대/인벤토리 제작, 제련·훈연·용광로, 화로 캠프파이어 요리, 석재 절단, 대장장이 제작의 제조 레시피를 제거합니다. 서버 시작과 /reload 이후 다시 반영합니다. TaCZ 총기 제작대 금지 로직은 기존대로 유지됩니다.
- **시설 이용 제한:** 제작대, 화로, 대장장이 작업대, 모루, 숫돌, 석재 절단기, 베틀, 지도 제작대, 양조기, 마법 부여대, 자동 제작기 등의 우클릭을 차단합니다.
- **허용된 상호작용:** 자연 생성 및 플레이어 설치 상자 열기·아이템 이동, 문, 레버와 버튼, **침대에서 리스폰 지점 지정/수면**은 계속 사용할 수 있습니다. 상자에 있는 아이템을 가져가는 행위는 아직 Phase 06의 팀·약탈 권한 시스템이 적용되지 않습니다.
- **맵 보호:** 폭발의 엔티티 피해는 유지하되 폭발에 의한 블록 파괴 목록을 지웁니다. 농지 짓밟기, 플레이어 물통/불붙이기/뼛가루를 통한 월드 수정을 제한합니다.
- **관리자 예외:** 권한 레벨 2 이상의 크리에이티브 관리자는 블록 배치·파괴와 제작 시설 상호작용이 가능합니다. 관리자가 설치한 블록은 소유자 기록 대상에서 제외합니다. 다만 서버 전역 레시피 제거는 관리자에게도 적용됩니다.

## 개발용 건축자재 지급

상인 시스템이 구현되기 전에는 치트가 활성화된 테스트 월드에서 다음 명령어로 재료를 지급합니다.

```mcfunction
/give @s zombieapocalypse:construction_planks 64
/give @s zombieapocalypse:construction_cobblestone 64
/give @s zombieapocalypse:construction_stone_bricks 64
/give @s zombieapocalypse:construction_glass 64
/give @s zombieapocalypse:construction_chest 4
```

이 아이템은 각각 가문비 판자, 조약돌, 석재 벽돌, 유리, 상자를 배치합니다. 상인은 앞으로 건축 전용 아이템을 팔면 됩니다. **예외로 바닐라 상자와 침대는 원본 아이템을 그대로 판매해도 설치할 수 있습니다.** 일반 판자·흙·조약돌 등 다른 바닐라 건축 블록은 여전히 설치할 수 없습니다.

## 필수 인게임 검증 (플레이어는 서바이벌, 테스트 권한은 별도 운영자)

1. 자연 생성 나무·돌·건물·상자를 캐면 부서지지 않아야 합니다.
2. 바닐라 판자·흙은 차단되고, **바닐라 상자와 침대는 설치되어야 합니다**.
3. 전용 건축자재를 배치하고 서버를 종료 후 재시작해도 해당 블록의 기록은 남아야 합니다.
4. 자신의 설치 블록은 철거할 수 있고, 다른 플레이어의 설치 블록은 철거할 수 없어야 합니다. 침대는 머리·발 부분 모두 소유권이 기록되며 자기 침대 전체만 철거할 수 있어야 합니다.
5. 2×2 인벤토리 및 3×3 조합대 제작, 화로·대장장이 작업대 사용이 차단되어야 합니다.
6. 건물의 기존 상자를 열어 물건을 꺼내고, 문을 열고 닫을 수 있어야 합니다.
7. TNT 폭발로 플레이어·감염자는 피해를 받지만 지형은 파괴되지 않아야 합니다.
8. TaCZ 허용 14종 사격과 감염자 소리 반응은 그대로 작동해야 합니다.

## 상인 판매 예정: 상자와 침대

- 상인 구현 시 `minecraft:chest` 및 `minecraft:red_bed` (또는 다른 색 침대)을 그대로 거래 아이템으로 넣을 수 있습니다. 별도 전용 아이템 없이 서바이벌 모드에서 설치 가능합니다.
- 기존 `zombieapocalypse:construction_chest`도 계속 지원하므로 이미 지급된 건축용 상자는 정상 작동해야 합니다.
- 플레이어가 설치한 상자는 `ConstructionLedger`에 소유자가 기록되어 **60분 파밍 상자로 자동 등록되지 않습니다.** 관리자가 `/za_loot register`로 지정하려 해도 거부되어야 합니다.
- 플레이어 소유 상자끼리는 옆에 배치할 수 있지만, **기존 도시 맵 상자에는 다른 소유 상자를 붙이지 못하도록 제한**합니다. 도시 맵 상자를 이중 상자로 바꾸는 것을 방지합니다.
- 침대는 머리와 발 양쪽의 소유권을 모두 기록합니다. 플레이어는 침대에 우클릭해 기본 마인크래프트 리스폰 지점을 설정할 수 있습니다. 이 기능은 서버의 기본 차원/수면 규칙을 따릅니다.
- 기존 월드/도시 상자는 여전히 채굴할 수 없습니다. 플레이어가 설치한 상자·침대는 소유자만 철거할 수 있습니다. 다른 플레이어의 상자 내용물 접근 권한은 추후 Phase 06에서 별도로 다룹니다.

### 추가 테스트

```mcfunction
/give @s minecraft:chest 2
/give @s minecraft:red_bed 1
/gamemode survival
```

1. 바닐라 상자를 설치하고 열어 물건을 넣은 뒤 `/za_loot register civilian`이 거부되는지 확인합니다. (관리자 권한으로 등록 명령어를 사용해야 합니다.)
2. 서바이벌에서 빨간 침대를 설치하고 우클릭해 리스폰 지점 메시지가 뜨는지 확인합니다.
3. 자신의 침대 머리 또는 발 쪽을 채굴하면 양쪽이 정상 제거되는지 확인하고, 재접속 후에도 소유권 기록이 올바른지 확인합니다.
4. 다른 플레이어는 내가 설치한 상자·침대를 파괴할 수 없어야 합니다.
5. 기존 맵 상자 옆에 바닐라 상자를 붙여 이중 상자로 만들려 할 때 설치가 거부되어야 합니다.

## 현재 범위 밖

- **상인/거래/재료 가격**은 Phase 04. 현재 전용 건축자재는 관리자 테스트 지급만 가능합니다.
- **일반 블록 채굴 드롭 재활용**은 허용하지 않습니다. 플레이어가 설치한 건축자재를 캐면 원래 바닐라 블록이 떨어질 수 있으나, 이 일반 아이템은 다시 배치할 수 없습니다. 건축물 회수·재료 환급 기능은 별도 작업입니다.
- 추후 추가할 팀 공유 건축물, 개인 창고, 상자 약탈·세분화된 접근권한은 Phase 06입니다.
- 피스톤, 엔더맨, 화재 확산, 흘러 들어오는 유체, WorldEdit·명령어·다른 모드에 의한 월드 편집까지 완전히 막는 일반-purpose 토지 보호 모드는 아닙니다. 운영 월드에선 `mobGriefing=false`, `doFireTick=false` 등의 gamerule을 추가로 사용하는 것을 권장합니다.
- 레시피가 삭제된 뒤 다른 모드에서 레시피를 다시 삽입하는 특수 경우는 추가 통합 테스트가 필요합니다.
