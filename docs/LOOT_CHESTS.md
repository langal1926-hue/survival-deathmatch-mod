# Phase 03 — 60분 파밍 상자 및 지역별 루팅

Minecraft 1.21.1 / NeoForge 21.1.264 / TaCZ r7. 전리품 생성과 타이머는 모두 **서버**에서 처리합니다.

## 왜 명시적으로 등록하나요?

- 서버에서 **OP가 지정한 맵 상자만** 파밍 대상으로 등록합니다. 모든 기존 상자를 자동 탐색하거나 새로 설치된 상자를 자동 등록하지 않습니다.
- Phase 02의 `ConstructionLedger`에 플레이어 소유 기록이 있는 상자는 등록할 수 없습니다. 개인 상자와 플레이어 창고는 건드리지 않습니다.
- 등록은 **단일 일반 상자(더블 체스트 불가)**, **비어 있는 상자**만 가능합니다. 기존 물건이나 바닐라 미개봉 보물 상자의 내용물을 삭제하지 않도록 운영자가 기존 상자를 열고 비워야 합니다.
- 상자를 깨거나 다른 블록으로 대체하면(일반적인 플레이어 이벤트) 등록을 자동 해제합니다. 명령어·월드 편집기로 치환한 경우는 검사를 통해 다음 활성 청크 주기에서 해제합니다.
- 개인 창고를 맵 상자로 등록하지 않도록 관리자 권한을 신뢰합니다. 이전 버전에서 설치된, 소유자 기록이 없는 개인 상자는 운영자가 지정하지 않아야 합니다.

## 관리자 명령어 (OP 2 이상)

빈 단일 **맵 상자를 6블록 이내에서 바라보면서** 실행합니다.

```mcfunction
/za_loot register civilian
/za_loot register hospital
/za_loot register police
/za_loot register military
/za_loot status
/za_loot refill
/za_loot unregister
/za_loot count
/za_loot audit
```

- `register`: 빈 상자에 즉시 첫 파밍 전리품을 생성합니다. **등록 시점에는 60분 타이머가 시작되지 않습니다.** 모든 아이템이 없어지면 그때부터 카운트다운이 시작됩니다.
- `status`: 상자에 아이템이 남아 있으면 **'완전히 비워야 타이머 시작'**을, 빈 상자라면 **재보급까지 남은 시간**을 출력합니다.
- `refill`: 운영자용 테스트 명령어로 **완전히 빈 상자**를 60분 대기 없이 즉시 채웁니다. 물건이 하나라도 남아 있으면 실행을 거부합니다. 생성 후에는 다시 상자를 모두 비울 때까지 타이머가 시작되지 않습니다.
- `unregister`: 재보급 지정만 해제합니다. 기존 상자 내용물은 삭제하지 않습니다.
- `count`: 현재 차원에 등록된 맵 상자 수.

## 프로필별 총기 드롭 확률 (사용자 확정 밸런스)

**상자 최초 등록 또는 자동/수동 재보급 한 번에 총기 카테고리를 단 한 번 추첨**합니다. 한 번의 보급에서 총기는 최대 **1정**이며, 당첨되지 않으면 식량·의료 물자·탄약·귀중품만 생성됩니다. 모든 확률은 상자 슬롯별 확률이 아니라 **보급 1회당 확률**입니다.

| 총기 분류 | 민가 `civilian` | 병원 `hospital` | 경찰서 `police` | 군사기지 `military` |
| --- | ---: | ---: | ---: | ---: |
| 권총 | 3% | 3% | 20% | 7% |
| 산탄총 | 2% | 2% | 15% | 10% |
| 기관단총 | 1% | 1% | 10% | 10% |
| 돌격소총 | 0% | 0% | 0% | 27% |
| 저격총 | 0.3% | 0.3% | 0.5% | 10% |
| 총기 등장 확률 합계 | 6.3% | 6.3% | 45.5% | 64% |
| 총기가 등장하지 않을 확률 | 93.7% | 93.7% | 54.5% | 36% |

총기 종류가 선택되면 그 분류의 허용 모델 중 **균등 무작위로 한 정**을 선택합니다.

- 권총: Glock 17, M1911, Desert Eagle
- 산탄총: DB-2 Durin, M870, M1014
- 기관단총: MP5A5, UMP45
- 돌격소총: AK47, M4A1, AUG, SCAR-H
- 저격총: M700, AWP

총기 모델은 기존 TaCZ 14종 서버 화이트리스트를 검증한 후 생성됩니다. 해당 TaCZ 총기 데이터가 로드되지 않은 경우 당첨되더라도 실제 총기가 나오지 않을 수 있습니다.

**일반 전리품**: 민가는 식량·귀중품·균등 탄약, 병원은 의료 물자·식량·소량의 균등 탄약, 경찰서는 균등 탄약·식량·귀중품, 군사기지는 균등 탄약·식량·귀중품이 등장합니다. 각 보급은 기존과 같이 총 **3~6개 묶음**을 추가하고, 총기가 당첨되면 그중 한 슬롯을 사용합니다.

상자에 이미 들어 있는 물건은 지우지 않습니다. 빈 슬롯이 없으면 아무것도 생성되지 않으므로, **위 확률은 빈 슬롯이 있고 해당 TaCZ 총기 모델이 정상 로드된 경우의 추첨 확률**입니다.

## 탄약 및 총기 부착물 파밍 (균등 탄종 / 총기별 호환)

- **탄약 균등 분포:** 총기 14종의 TaCZ 원본 데이터에서 실제 `ammoId`를 읽고 중복된 탄종은 하나로 합칩니다. 이후 탄약 묶음이 당첨되면 **서로 다른 모든 탄종을 같은 확률(각 1/N)**로 선택합니다. 9mm나 5.56mm가 여러 총기에 쓰이더라도 유리하지 않습니다.
- 민가·병원은 탄약 묶음 **4~13발**, 경찰서는 **8~20발**, 군사기지는 **12~28발**입니다. 병원에도 소량의 탄약이 추가됩니다. 지역에 따라 탄약 묶음 자체가 나올 가능성은 달라도, **당첨된 탄종의 분포는 모든 지역에서 균등**합니다.
- **총기 부착물:** 기존 총기와는 **별도로**, 한 번의 상자 보급당 부착물 계열을 1회 추첨합니다. 부착물 카테고리의 등장 확률은 동일 지역의 **해당 총기 카테고리 확률과 같습니다.** 예: 군사기지에서 돌격소총용 조준경/소음기가 나올 추첨 확률 27%, 저격총용은 10%; 민가에서 권총용은 3%, 저격총용은 0.3%.
- 카테고리가 선택되면 그 안에서 **허용 부착물이 최소 1개 있는 총기 모델 중 균등 선택**합니다. 선택한 모델이 조준경과 소음기를 둘 다 허용하면 각 50%로 선택하며 하나만 허용하면 그 하나만 나옵니다.
- **실제 호환성 검사:** `tacz_weapon_allowlist.json`에서 각 총기에 허용된 조준경과 소음기만 생성합니다. TaCZ 아이템은 `AttachmentItemBuilder`를 사용해 올바른 데이터 ID를 가집니다. M1911처럼 조준경이 없는 총기는 소음기만, DB-2 Durin처럼 둘 다 없는 총기는 부착물을 생성하지 않습니다. 내장 조준경은 별도 전리품으로 생성하지 않습니다.
- 재보급 1회당 총기 최대 1정, 부착물 최대 1개입니다. **총기와 부착물은 서로 독립 추첨**되므로 같은 상자에서 꼭 세트로 나오지는 않습니다. 식량/의료 물자/귀중품/탄약과 함께 기존의 총 **3~6개 묶음**을 사용합니다. **자동 재보급은 완전히 빈 상자에서만 실행**됩니다.
- 기존 총기 드롭 확률, 플레이어 개인 상자 재보급 제외 및 60분 쿨타임 길이는 유지합니다. 단, **60분 쿨타임 시작 시점은 마지막 아이템을 빼내 상자가 완전히 빈 순간으로 변경되었습니다.**

### 탄약·부착물 인게임 테스트

1. 민가·경찰서·군사기지의 지정 상자를 **완전히 비우고** `/za_loot refill` 명령어로 재보급하면서 탄약 ID가 다양하게 등장하는지 확인합니다. 기존 전리품이 남아 있으면 명령어는 거부됩니다.
2. 5.56mm, 9mm 이외의 탄종도 확인하고, 그 탄약으로 실제 해당 TaCZ 총기를 재장전할 수 있는지 확인합니다.
3. 군사기지에서 돌격소총용 조준경·소음기, 경찰서에서 권총·SMG용 부착물이 나오는지 확인합니다.
4. 부착물을 해당 총기에 설치하고 허용 목록 검사에서 제거되지 않는지 확인합니다. 지원하지 않는 부착물/내장 조준경은 파밍되면 안 됩니다.
5. **확률 테스트는 대량 반복으로 확인**해야 합니다. 낮은 확률의 저격총용 부착물은 소수의 상자를 열어서는 나오지 않을 수 있습니다.

## TaCZ 미허용 조준경/부착물 유입 차단 및 점검

### 원인 후보와 대응

- 우리 모드의 `LootChestFiller`는 허용 총기에 지정된 부착물만 생성합니다. 이번 수정에서는 **완성된 TaCZ 아이템 스택의 실제 부착물 ID**까지 다시 검사하여 허용되지 않은 장비가 들어가지 않도록 했습니다.
- **TaCZ 원본 모드**에도 일반 Minecraft 루트 테이블에 전리품을 추가하는 별도의 글로벌 전리품 수정기가 있습니다. 기존 서버 규칙은 플레이어가 금지 장비를 주운 *후에야* 제거했으므로, 금지 조준경이 상자에 남아 있을 가능성이 있습니다.
- 이제 NeoForge **글로벌 전리품 수정기**에서 새로 생성된 TaCZ 총기/부착물의 허용 여부를 지급 전에 검사합니다. TaCZ 모드나 원본 루트 인젝터는 수정하지 않으며 일반 물자와 탄약은 유지합니다.
- **서버에서 허용되는 조준경도 모든 총기에 장착할 수 있는 것은 아닙니다.** 각 총기에 지정된 조준경만 장착됩니다. 다른 총기에 장착하면 서버의 장착 제한 때문에 해제될 수 있습니다.

### 문제 아이템 ID 진단 (OP)

의심되는 일반 상자를 6블록 안에서 바라보고 실행하세요.

```mcfunction
/za_loot audit
```

- 상자 속 TaCZ 부착물 ID, 서버 허용/금지 여부, 그 부착물을 장착할 수 있는 허용 총기들을 표시합니다. 등록되지 않은 일반 상자에서도 확인할 수 있습니다.
- 읽기 전용 명령어이므로 기존 아이템과 상자 내용은 변경하지 않습니다.
- 기존 버전에서 이미 생성되어 저장된 금지 조준경은 새 생성 필터가 소급 삭제하지 않습니다. 기존 상자는 관리자가 확인하고 정리한 후 다시 테스트해야 합니다.
- 다른 추가 모드가 새 전리품을 뒤늦게 삽입하는 경우 등 실제 통합 동작은 인게임 확인이 필요합니다. 동일 문제가 반복되면 `/za_loot audit`의 정확한 `tacz:*` ID를 기록해 주세요.

## 60분 타이머: 완전히 빈 상자에서 시작

1. 운영자가 `/za_loot register civilian` 등으로 **비어 있는 단일 맵 상자**를 등록하면 즉시 전리품이 생성됩니다. **이 시점에는 타이머가 없습니다.**
2. 플레이어가 물건을 가져가도 **1개라도 상자 안에 남아 있다면** 아무런 카운트다운이 돌지 않습니다.
3. **마지막 아이템까지 꺼내 상자가 완전히 비면**, 서버가 빈 상태를 확인한 순간 **60분 카운트다운**을 시작합니다.
4. 60분 동안 상자가 계속 빈 상태이면 전리품 3~6묶음을 새로 생성하고 다시 **타이머 대기 상태**로 전환합니다.
5. 카운트다운 중 상자에 **물건을 다시 넣으면 진행 중인 60분 타이머는 취소**됩니다. 이후 다시 완전히 비우면 새로 60분부터 시작합니다.
6. 완전히 비운 상자의 남은 카운트다운은 **서버 재시작 후에도 유지**됩니다. 서버가 꺼져 있는 동안 60분이 지나면 청크가 다시 로드되고 상자가 여전히 비었을 때 한 번만 재보급합니다.

- 등록된 상자마다 상태와 다음 보급 예정 시각을 **실제 시간(UTC 에포크 밀리초)**으로 차원별 SavedData에 저장합니다.
- 활성 서버에서 **5초(100틱)마다** 등록된 상자만 검사하므로, **마지막 아이템을 가져간 후 타이머 시작까지 최대 약 5초의 지연**이 생길 수 있습니다. `/za_loot status`로 즉시 확인할 수도 있습니다.
- 청크가 로드되지 않으면 강제 로딩하지 않습니다. 아직 등록돼 있지만 한 번도 빈 상태가 확인되지 않은 상자는 청크가 다시 로드될 때부터 시작합니다.
- **구버전 월드 자동 전환:** 이전의 '재보급 직후 60분' 타이머는 무효화하고, 등록 위치와 프로필은 그대로 유지합니다. 첫 빈 상태 확인 시점부터 새 규칙을 적용해 이전 타이머 때문에 상자가 뜻하지 않게 채워지는 일을 막습니다.
- **운영자 수동 명령:** `/za_loot refill`은 상자를 **완전히 비웠을 때만** 60분을 기다리지 않고 즉시 생성합니다. 일반 자동 재보급 규칙과 구분됩니다.
- 플레이어가 설치한 상자/개인 창고는 기존처럼 **등록·재보급 대상에서 제외**됩니다. 기존 아이템은 삭제하지 않습니다.

## 실제 인게임 검증

1. 운영자 크리에이티브로 맵에 **단일 일반 상자** 설치 → 열어 빈 상자 상태 확인 → `/za_loot register civilian`.
2. 바로 상자를 열어 음식·귀중품·TaCZ 권총/산탄총 등이 출현하는지 확인 (랜덤이므로 매회 총이 나오는 것은 아님).
3. 상자에 물건을 **1개 남기고** `/za_loot status`를 실행 → 타이머 대기 상태여야 합니다. `/za_loot refill`도 차단되어야 합니다.
4. 다른 곳에 `/give @s zombieapocalypse:construction_chest`로 개인 상자 설치. `/za_loot register police`가 거부되며 개인 상자 내용이 유지되는지 확인.
