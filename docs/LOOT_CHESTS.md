# Phase 03 — 60분 파밍 상자 및 지역별 루팅

Minecraft 1.21.1 / NeoForge 21.1.264 / TaCZ r7. 전리품 생성과 타이머는 모두 **서버**에서 처리합니다.

## 왜 명시적으로 등록하나요?

- 서버에서 **OP가 지정한 맵 상자만** 파밍 대상으로 등록합니다. 모든 기존 상자를 자동 탐색하거나 새로 설치된 상자를 자동 등록하지 않습니다.
- Phase 02의 `ConstructionLedger`에 플레이어 소유 기록이 있는 상자는 등록할 수 없습니다. 개인 상자와 플레이어 창고는 건드리지 않습니다.
- 등록은 **단일 일반 상자(더블 체스트 불가)**, **비어 있는 상자**만 가능합니다. 기존 물건이나 바닐라 미개봉 보물 상자의 내용물을 삭제하지 않도록 운영자가 기존 상자를 열고 비워야 합니다.
- 상자를 깨거나 다른 블록으로 대체하면(일반적인 플레이어 이벤트) 등록을 자동 해제합니다. 명령어·월드 편집기로 치환한 경우는 검사를 통해 다음 활성 청크 주기에서 해제합니다.
- 개인 창고를 맵 상자로 등록하지 않도록 관리자 권한을 신뢰합니다. 이전 버전에서 설치된, 소유자 기록이 없는 개인 상자는 운영자가 지정하지 않아야 합니다.

## 관리자 명령어 (OP 2 이상)

빈 단일 **맵 상자를 6블록 이내에서 바라보면서** 실행합니다.

```mcfunction
/za_loot register civilian
/za_loot register hospital
/za_loot register police
/za_loot register military
/za_loot status
/za_loot refill
/za_loot unregister
/za_loot count
```

- `register`: 즉시 첫 파밍 전리품을 추가하고 **현재 시각부터 60분 후** 다음 보급을 예약합니다.
- `status`: 프로필과 남은 시간을 출력합니다.
- `refill`: 테스트용 즉시 보급. 빈 슬롯만 채우고 기존 아이템은 보존합니다. 60분 타이머가 새로 시작됩니다.
- `unregister`: 재보급 지정만 해제합니다. 기존 상자 내용물은 삭제하지 않습니다.
- `count`: 현재 차원에 등록된 맵 상자 수.

## 프로필/아이템 분포 (초기 밸런스)

| 프로필 | 예시 지역 | 전리품 |
| --- | --- | --- |
| `civilian` | 민가·편의점 | 식량·귀중품·권총 3종·산탄총 3종·권총 탄 |
| `hospital` | 병원·약국 | 꿀병, 물약(현재 물병 임시), 황금 당근, 드물게 황금 사과 |
| `police` | 경찰서 | 권총, MP5A5·UMP45, 권총/SMG 탄약, 귀중품 |
| `military` | 군사기지 | AK47·M4A1·AUG·SCAR-H·M700·AWP, AR/저격탄, 귀중품 |

- **총기 14종만** 출현합니다. 총기 ID는 기존 TaCZ 화이트리스트를 사용하고, 원본 TaCZ GunItemBuilder/AmmoItemBuilder로 발사 가능한 아이템을 생성합니다.
- 전리품은 카테고리별 가중치로 한 번에 **3~6개 묶음**을 무작위 슬롯에 배치합니다. 일부 총기·특수 아이템은 희귀합니다.
- **권총은 파밍**, **기관단총은 경찰서**, **돌격소총과 저격총은 군사기지**, **산탄총은 민가** 중심입니다. 미래의 암상인 판매와 별도로 적용됩니다.
- `GOLD_NUGGET` / `GOLD_INGOT`은 Phase 04 경제가 구현되기 전의 귀중품 자리표시자입니다. 병원 전용 의료 시스템/탄약 상세 밸런스도 나중에 조정할 수 있습니다.

## 60분 타이머 동작

- 등록된 상자마다 다음 보급 예정 시각을 **실제 시간(UTC 에포크 밀리초)**으로 차원별 SavedData에 저장합니다.
- 서버 재시작 후에도 예정 시각이 유지됩니다. 서버가 꺼진 동안 시간이 지났다면, 해당 상자 **청크가 다시 로드된 후** 보충됩니다.
- 활성 서버에서 5초(100틱)마다 **등록된 상자 위치만** 검사합니다. 미로드 청크를 강제로 불러오지 않습니다.
- 이미 차지한 슬롯은 건드리지 않고 **빈 슬롯만 보충**합니다. 가득 찬 상자는 0개를 추가하고 다음 60분으로 넘어갑니다.
- 서버 다운 시간이 몇 시간이어도 누적 회수를 한꺼번에 보충하지 않습니다 (재접속시 한 번만).

## 실제 인게임 검증

1. 운영자 크리에이티브로 맵에 **단일 일반 상자** 설치 → 열어 빈 상자 상태 확인 → `/za_loot register civilian`.
2. 바로 상자를 열어 음식·귀중품·TaCZ 권총/산탄총 등이 출현하는지 확인 (랜덤이므로 매회 총이 나오는 것은 아님).
3. 상자에서 물건 일부를 꺼낸 뒤 `/za_loot refill`을 실행 → 기존 아이템은 그대로 있고 빈 슬롯만 보충되는지 확인.
4. 다른 곳에 `/give @s zombieapocalypse:construction_chest`로 개인 상자 설치. `/za_loot register police`가 거부되며 개인 상자 내용이 유지되는지 확인.
5. 등록 후 `/za_loot status`의 다음 보충 시간을 확인하고 게임을 종료/재접속하여 남은 시간이 유지되는지 확인.
6. 상자 등록 해제 후 `/za_loot refill`이 거부되는지, 내용물은 유지되는지 확인.
7. 경찰서/군사기지 프로필을 등록해 허용된 총기만 출현하고 TaCZ 실제 발사·재장전이 가능한지 확인.
8. 멀티플레이로 접속해 개인 창고가 다른 사람의 지정과 상관없이 보존되는지 검사.

**주의:** 이번 구현은 '맵 상자'를 관리자가 명시적으로 지정하는 방식입니다. 도시 전체 건물을 자동 인식해 상자 유형을 추론하지 않으며, 좀비 사망 시 아이템·귀중품 드롭과 암상인/경제는 다음 작업입니다.
